# Chortle piece sets

The additional SVG sets in this directory were sourced from [deverac/piece-packager](https://github.com/deverac/piece-packager), whose collection credits the original artists and sources. Only sets with a redistribution-friendly license are shipped in the beta build.

- `merida` — Armando Hernandez Marroquin; GPLv2+; source: <https://sharechess.github.io>
- `mono` — Thibault Duplessis and Colin M. L. Burnett; source: <https://github.com/deverac/piece-packager>

The `chessnut` files are the existing local set, while Cburnett is bundled by Chessground.

The removed non-commercial sets remain available from the upstream collection,
but are intentionally not redistributed by this project.
